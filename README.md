# Juego del Ahorcado en PHP

Un sencillo juego del ahorcado desarrollado en PHP.

## Cómo jugar
1. Ejecuta el servidor local (XAMPP, Apache o similar).
2. Abre `index.php` en el navegador.
3. Introduce letras para adivinar la palabra secreta.
4. Tienes 6 vidas.
5. Si ganas o pierdes, aparecerá una pantalla final con opción de jugar de nuevo.

## Créditos
Actividad AE01 – Despliegue de Aplicaciones Web (DAW)
